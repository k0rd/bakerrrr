# Reporting Bugs

Thank you for catching the strange bit and telling us where it bit you.

The best bug report is short, concrete, and honest about what you remember. You do not need to diagnose the game.

Useful things to include:

- Your OS.
- Whether you used a packaged build or source launch.
- The command you used, if you launched from source.
- Whether it happened in the tutorial or a normal run.
- The last visible message or menu you remember.
- What you expected to happen.
- What happened instead.
- If a crash file exists, mention `saves/bakerrrr_last_crash.txt`.

Optional but helpful:

- A screenshot.
- The run summary shown after the game ends.
- A rough description of where you were: street, shop, vehicle map, notebook, inventory, dialogue, or combat.

Please avoid posting surprise discoveries in public titles if you can. A little mystery is load-bearing around here.
